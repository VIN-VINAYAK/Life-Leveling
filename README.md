# Life Leveling 🚀

A gamified personal development platform where users level up through completing tasks and maintaining streaks.

## Phase 1: Core Prototype
- Login/Register
- Dashboard
- XP system
- Tasks
- Basic leveling

## Tech Stack
- **Frontend**: React + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: MongoDB
- **Auth**: JWT

## Getting Started

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```
